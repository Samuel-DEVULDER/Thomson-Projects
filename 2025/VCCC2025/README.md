# VCCC2025 

Small collection of 6809 assembly demos that draw small star/flake patterns to the Thomson screen. Each *.ass is an assembly variant (sizes noted in source comments).

Sumitted files:
- sam_thomsonto8_6809assembly_85b_vc3-2025 — Submitted file for Thomson TO8.
- sam_squaleapollo7_assemblera09_133b_vc3-2025 — Submitted file Squale Apollo 7 / Flex9.
  
Unpublishezd Files:
- V85.ass — 85-byte version: prints a 19×19 bitmap by shifting/rotating bits (compact bitmap renderer).
- V95.ass — 95-byte version: plots symmetric points (mirrored 4‑way star drawing routine).
- V98.ass — 98-byte version: similar symmetric/star plotter with different layout/parameters.
- V104.ass — 104-byte version: uses a “turtle” drawing routine and macros to produce a flake pattern.
- V119.ass — 119-byte version: larger/expanded variant with more layered drawing routines.
