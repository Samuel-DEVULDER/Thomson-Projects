# Thomson
Various projects for the Thomson machines.

* [2010/rotozoom](2010/rotozoom) - compact rotozoom graphics demo (rotating + zooming bitmap effect)
* [2011/firew](2011/firew) - fireworks visual demo for Puls/Thomson platforms
* [2012/TO-ale](2012/TO-ale) - 256-byte bootblock demo that draws animated spider-web-like patterns (TO-ALE)
* [2012/boing](2012/boing) - bouncing-ball-style graphics demo
* [2013/hny2013](2013/hny2013) - New-Year 2013 music demo using the hardware programmable timer
* [2013/foreverXIV-elvislives](2013/foreverXIV-elvislives) - slideshow demo (Elvis theme) created for Forever Party XIV
* [2013/foreverXIV-rockfort](2013/foreverXIV-rockfort) - intro/demo piece made for Forever Party XIV
* [2014/foreverXV-PiMiTV](2014/foreverXV-PiMiTV) - demo produced for Forever Party XV
* [2014/foreverXV-TopOPop](2014/foreverXV-TopOPop) - music/graphics demo for Forever Party XV
* [2014/foreverXV-WRBP](2014/foreverXV-WRBP) - demo built for Forever Party XV
* [2015/PIrat](2015/PIrat) - tiny (256-byte) intro that computes digits of Pi on the fly
* [2015/forever-2015-thomcat](2015/forever-2015-thomcat) - Forever Party 2015 intro ("thomcat")
* [2015/langton](2015/langton) - Langton's ant cellular-automaton demonstration
* [2015/sindots](2015/sindots) - 256-byte intro rendering animated Lissajous-like patterns
* [2016/def1bit](2016/def1bit) - minimal 1-bit graphics intro created for Forever Party
* [2016/quatropic](2016/quatropic) - port of the ZX Spectrum "Quatropic" music player to Thomson
* [2016/sowebuzz](2016/sowebuzz) - karaoke-style demo (text/music) for Forever Party
* [2017/forever-2017-deMODed](2017/forever-2017-deMODed) - TO8 MOD music player with synchronized graphics for Forever Party 2017
* [2019/forever-2019](2019/forever-2019) - music and graphics demo for the TO770 (Forever 2019 entry)
* [2019/fpu](2019/fpu) - software implementation of stack-based fast 16bit floating-point operations with very limited precision (reduces shift operation, only 8-9 bits of precisions)
* [2021/Sudoku](2021/Sudoku) - Sudoku solver/generator implementation
* [2022/ZPU](2022/ZPU) - ZPU emulator: 32-bit stack-based CPU emulator
* [2024/raytrace](2024/raytrace) - compact, high-performance ray tracer (optimized floating-point operations)
* [2025/VCCC2025](2025/VCCC2025) - ultra-small asm demos that draws snowflakes (VCCC 2025)
* [exobin/exomizer2](exobin/exomizer2) - Exomizer2-based tools to compress Thomson binaries
